The 4 patterns that appear in every PyKit program
1

Import — Load your tools

import pykit_explorer             # always first
from neopixels  import NeoPixels, Colors
from imu_sensor import IMUSensor
from digital_io import DigitalInput
Pattern: from <filename> import <ClassName>
Filename = the module (e.g. neopixels). ClassName = what you'll use (e.g. NeoPixels). Only import what your project needs.
2

Create — Set up your hardware

# One line per piece of hardware
px  = NeoPixels()
imu = IMUSensor()
btn = DigitalInput(board.D3)

# I2C sensors need a bus first
i2c    = I2CBus()
sensor = BME680Sensor(i2c.bus)
Pattern: name = ClassName()
This is called instantiation. You only do it once at the top of your program. After this, px is your NeoPixels — forever.
3

Call — Make things happen

# Tell hardware what to do
px.fill(Colors.RED)       # all pixels red
px.off()                   # all pixels off
px.set(0, Colors.BLUE)    # pixel 0 = blue

# Ask hardware for data
direction = imu.tilt_direction()   # "LEFT" / "RIGHT" etc
pressed   = btn.is_pressed()       # True or False
Pattern: object.method()
The dot connects your variable to an action. Some calls do something (like turning on LEDs). Others return a value you can save and use.
4

Loop + Decide — React to the world

while True:                        # run forever
    direction = imu.tilt_direction()

    if   direction == "LEFT":
        px.fill(Colors.RED)
    elif direction == "RIGHT":
        px.fill(Colors.BLUE)
    else:
        px.off()

    time.sleep(0.05)              # short pause
Indentation matters. Everything inside while True: must be indented. Everything inside if/elif/else: must be indented again. Use 4 spaces.

F-strings — Display data

temp = CPUTemperature()
c = temp.celsius

# Put a variable inside { }
print(f"Temp: {c} C")
print(f"Temp: {c:.1f} C")   # 1 decimal

# Works with any variable
print(f"Tilt: {imu.tilt_direction()}")
Start the string with f"..." — then put any variable or expression inside { }. The :.1f means "1 decimal place."

Complete 9-line program

import pykit_explorer, time
from imu_sensor import IMUSensor
from neopixels import NeoPixels, Colors

imu = IMUSensor()
px  = NeoPixels()

while True:
    tilt = imu.tilt_direction()
    if   tilt == "LEFT":  px.fill(Colors.RED)
    elif tilt == "RIGHT": px.fill(Colors.BLUE)
    elif tilt == "UP":    px.fill(Colors.GREEN)
    else:                  px.off()
    time.sleep(0.05)
This is a complete, working program. It uses all 4 patterns. Tilt the board to change the NeoPixel colour.

3 errors you'll see today

!
IndentationError
Your spacing is off. Everything inside a while or if must be indented exactly 4 spaces. Don't mix tabs and spaces.
!
NameError: name 'px' is not defined
You used a variable before creating it. Make sure px = NeoPixels() appears before the while True: loop.
!
ImportError
The module file isn't on the CIRCUITPY drive, or you spelled it wrong. Check the /API folder matches your import statement.

Level up — when your first project is done
async_tasks · AsyncRunner

⚡ Do two things at once with AsyncRunner

The problem with time.sleep() — while the board is sleeping, it can't do anything else. One blink blocks everything. AsyncRunner solves this with cooperative multitasking: each task runs a little, then yields to the others.
The two rules:
1. Your function must start with async def
2. Replace time.sleep() with await AsyncRunner.sleep()
When to reach for it: you want two (or more) things happening simultaneously — blinking LEDs while polling a sensor, playing audio while updating the display, running a timeout alongside user input. 
import pykit_explorer
from neopixels   import NeoPixels, Colors, OFF
from async_tasks import AsyncRunner

px = NeoPixels()

# async def — like a normal function, but pauseable
async def blink(pixel, interval, color):
    while True:
        px.set(pixel, color)
        await AsyncRunner.sleep(interval)  # yield here
        px.set(pixel, OFF)
        await AsyncRunner.sleep(interval)

# All three run concurrently — none blocks the others
runner = AsyncRunner()
runner.add(blink(0, 0.30, Colors.RED))
runner.add(blink(1, 0.75, Colors.GREEN))
runner.add(blink(2, 1.00, Colors.BLUE))
runner.run()                        # starts all tasks
✗ Before — blocking
while True:
    px.set(0, Colors.RED)
    time.sleep(0.5)   # board frozen here
    px.set(0, OFF)
    time.sleep(0.5)   # board frozen here
    # pixel 1 never blinks — it's waiting
✓ After — concurrent
async def blink(pixel, interval, color):
    while True:
        px.set(pixel, color)
        await AsyncRunner.sleep(interval)
        px.set(pixel, OFF)
        await AsyncRunner.sleep(interval)
# all pixels blink independently
The mental model: think of each async def function as a separate worker. await is the moment a worker puts up their hand and says "I'm waiting — someone else can go." The runner keeps cycling through workers until everyone is done waiting, then repeats. No worker ever interrupts another mid-instruction — only at await points.
